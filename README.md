# WaffleMC textures

Resource packs for the WaffleMC legendary items.

- `WaffleMC-Pack.zip` - Java resource pack (server resource pack link).
- `geyser/WaffleMC-Bedrock.mcpack` - Bedrock pack for Geyser `packs/` folder.
- `geyser/waffle_items.json` - Geyser mapping for Geyser `custom_mappings/`.
- `source-java/`, `source-bedrock/` - editable sources. `generate.py <outdir>` rebuilds the placeholder art and zips.
